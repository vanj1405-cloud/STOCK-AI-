STOCK AI V4.1

INSTALL
1. Extract the ZIP.
2. Open PowerShell in Stock-AI-V4.1.
3. Run:
   python -m pip install -r requirements.txt
4. Double-click Start-Stock-AI.bat

NEW IN V4.1
- Automatic asset classification
- Separate handling for equities / ETFs / indices / crypto / FX
- Comparison against broad market
- US sector ETF comparison when available
- TA-listed equities attempt to compare against TA-125
- Historical analog engine ("what happened in similar states?")
- Better support/resistance zones
- Pattern detection and fundamentals remain modular

Important:
Yahoo Finance coverage varies. The program will not fabricate missing data.
